## 🧮 01. BMI Calculator

A modern desktop BMI Calculator built with **Python and Tkinter**.

### ✨ Features

* 🇬🇧 English / 🇮🇷 Persian interface
* 🔄 Language switching
* 🌐 RTL / LTR interface support
* 💾 Saves the selected language locally
* 🧮 BMI calculation
* 📊 BMI category detection
* ⚖️ Healthy weight range calculation
* ✅ Input validation
* ⚠️ Bilingual error messages
* 🔄 Reset functionality
* ⌨️ Keyboard shortcuts
* 🌙 Modern dark UI
* 🧱 Object-Oriented Programming
* 🚫 No external libraries required

### 🛠️ Technologies

* Python 3
* Tkinter
* JSON
* Object-Oriented Programming
* File Handling
* Exception Handling

### ▶️ Run

```bash
cd bmi-calculator
python BMI.py
```
