# ✅ TaskFlow — Professional To-Do App

A modern bilingual desktop task manager built with **Python + CustomTkinter**.

## ✨ Features
- 🇬🇧 English / 🇮🇷 Persian
- 🌙 Dark Mode / ☀️ Light Mode
- 💾 Persistent settings and task data
- ➕ Add, ✏️ edit, 🗑️ delete and ✅ complete tasks
- 🔎 Live search
- 🚦 Low / Medium / High priorities
- 🏷️ Work / Study / Personal / Shopping / Other categories
- 📅 Due dates with validation
- ⚠️ Overdue and Today filters
- 📊 Statistics and progress percentage
- 🔃 Newest / Oldest / Priority / Due-date sorting
- 📝 Task descriptions
- 🆔 Unique task IDs
- 🕒 Created and updated timestamps
- 🧹 Clear completed tasks
- 🎨 Modern CustomTkinter interface
- 📦 JSON persistence without a database

## 📦 Install
```bash
pip install customtkinter
```

## ▶️ Run
```bash
python todo.py
```

## 📂 Structure
```text
todo-app/
├── todo.py
├── README.md
├── tasks.json       # generated automatically
└── settings.json    # generated automatically
```

Python OOP, CustomTkinter, GUI events, CRUD, JSON, file handling, search/filter/sort, date validation, persistent state and UI/UX.
