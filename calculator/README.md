# 🧮 ProCalc — Professional Calculator

A modern scientific desktop calculator built with **Python and Tkinter**.

## ✨ Features

- Basic arithmetic
- Scientific functions
- `sin`, `cos`, `tan`
- Inverse trigonometric functions
- Square root, power and factorial
- Percentage
- `π` and `e`
- DEG / RAD modes
- Memory: MC, MR, M+, M-, MS
- Calculation history
- English / Persian interface
- Dark / Light theme
- Keyboard shortcuts
- Clipboard copy
- Persistent settings with JSON
- Safe expression evaluation with `ast`
- Object-Oriented Programming
- No external packages

## ▶️ Run

```bash
python calculator.py
```

Windows:

```bash
py calculator.py
```

## 📂 Structure

```text
calculator/
```

## ⌨️ Keyboard

| Key | Action |
|---|---|
| Enter | Calculate |
| Backspace | Delete |
| Escape | Clear |
| Ctrl + C | Copy result |
| `+ - * /` | Operators |
| `0-9` | Numbers |
