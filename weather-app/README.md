# 🌤️ Weather App

A modern desktop weather application built with **Python and CustomTkinter (CTk)**.

The app uses **Open-Meteo** for geocoding and weather data, so no API key is required.

## ✨ Features

- 🌤️ Real-time weather information
- 🔎 City search
- 📍 Location coordinates
- 🌡️ Current temperature
- 🤔 Feels-like temperature
- 💧 Humidity
- 💨 Wind speed
- 🧭 Atmospheric pressure
- 👁️ Visibility
- 🌅 Sunrise
- 📅 5-day forecast
- 🇬🇧 English / 🇮🇷 Persian interface
- 🔄 Language switching
- 🌙 Modern dark UI
- 🖥️ CustomTkinter interface
- 🌐 Real API integration
- ⚡ Background requests with threading
- 🚫 No API key required

## 🌐 APIs

This project uses:

- **Open-Meteo Geocoding API** — converts a city name into coordinates.
- **Open-Meteo Forecast API** — retrieves current weather and forecast data.

No API key or account is required.

## 📦 Installation

Install the required packages:

```bash
pip install customtkinter requests
```

Or:

```bash
py -m pip install customtkinter requests
```

## ▶️ Run

```bash
python weather.py
```

Windows:

```bash
py weather.py
```
